# FRP 商业平台新手快速上手 · 0.2.0

控制台域名是 `frpc.hhse.top`，默认转发节点域名是 `frps.hhse.top`，管理员邮箱是 `hzx0851@gmail.com`。域名是你的平台标识，**先在 DNS 管理页把两个域名的 A 记录指向同一台 Linux 控制服务器的公网 IPv4**；若使用 IPv6，AAAA 记录也必须指向可达的公网 IPv6。DNS 生效后再安装。

## 第一次安装控制服务器

准备 Debian 12 或 Ubuntu 22.04/24.04、amd64/arm64、systemd 宿主。云安全组和本机防火墙放行 TCP 80/443、TCP 17100–17199，以及 TCP/UDP 20100–20199。服务器需要能访问 GitHub、系统软件源和 Let’s Encrypt。

在这台服务器复制执行：

```bash
curl -fL https://raw.githubusercontent.com/huang199800/frp-business/main/install.sh -o /tmp/frp-install.sh && sudo bash /tmp/frp-install.sh --domain frpc.hhse.top --node-domain frps.hhse.top --email hzx0851@gmail.com
```

脚本会下载与 CPU 匹配的发布包，先验证固定公钥签名及哈希，再安装 PostgreSQL、Caddy、控制服务、默认节点和默认套餐。首次输入并确认管理员密码；随后会显示一次 TOTP 密钥，请立即添加到认证器并离线保存。脚本不会替你修改 DNS、安全组或域名注册商配置。

安装成功后打开 <https://frpc.hhse.top>。登录需要邮箱、密码、认证器当前 6 位码。默认套餐仅用于体验；正式收费规则请在“套餐与节点”创建，再到“充值码管理”生成卡密并交付客户。当前版本没有在线支付接口，不应把“参考价格”当作已收款金额。

## 已安装控制服务器升级

原机执行以下命令即可，无需再次填写域名、邮箱或数据库密码：

```bash
curl -fL https://raw.githubusercontent.com/huang199800/frp-business/main/install.sh -o /tmp/frp-install.sh && sudo bash /tmp/frp-install.sh --upgrade
```

安装器只接受已有的一键安装状态；会先做配置和 PostgreSQL 备份，再迁移数据库及切换程序。原管理员、套餐、充值账目、设备、域名和节点身份保留。程序启动失败会尝试切回旧程序；数据库迁移不自动逆转，备份位置在 `/var/backups/frp-portal/`。升级前建议安排短维护窗口，并确认有足够磁盘空间。

## 再加一台 Linux 转发节点

1. 为新服务器准备**新的节点域名**，例如 `edge2.hhse.top`，将其 A/AAAA 记录解析到新服务器公网地址。放行 TCP 80（证书签发与续期）、控制端口池 TCP、业务端口池 TCP/UDP。
2. 登录控制台，打开“套餐与节点 → 添加转发节点”，填写新节点名称、域名及互不重叠的本机端口段，点击“生成节点安装命令”。端口段可以和另一台服务器相同，但同一台机器上的控制/业务端口段不能重叠。
3. 控制台会显示一条**不含密钥**的完整命令。把命令复制到新服务器执行；终端询问专属密钥时再粘贴网页显示的一次性密钥。不要把密钥拼进命令行、截图公开或发进聊天群。
4. 安装器自动向控制台校验身份、申请 Let’s Encrypt 节点证书、注册 `frp-portal-node` 服务，并保存 root-only 升级状态。回到控制台刷新“节点状态”，出现“最近通讯”后，为此节点创建套餐。

新节点**不安装 PostgreSQL 或控制台**。它使用自己的公网证书；默认节点仍使用平台私有 CA。客户端会根据节点类型自动选择信任方式。

已安装远程节点升级，在该节点服务器运行：

```bash
curl -fL https://raw.githubusercontent.com/huang199800/frp-business/main/install.sh -o /tmp/frp-install.sh && sudo bash /tmp/frp-install.sh --node-only --upgrade
```

节点身份和证书保留，升级前备份在 `/var/backups/frp-portal/node-*/`。若新的节点域名尚未解析到正确公网 IP，或 80 端口被占用，自动证书签发会失败，请先修正 DNS/防火墙并重试。

## 客户开始使用

客户注册、兑换卡密、生成 5 分钟绑定码，然后下载匹配系统的客户端压缩包。Windows 或 Linux 都可运行 `portal connect`；更方便的是使用压缩包里的安装脚本，它会配置登录/用户服务自启。服务器地址、端口、专属密钥、CA、连接池和日志默认值自动配置。具体步骤和排错见[客户端快速上手](客户端快速上手.md)。

常用检查：

```bash
systemctl status frp-portal-serve frp-portal-node caddy
curl --fail https://frpc.hhse.top/healthz
journalctl -u frp-portal-node -n 80 --no-pager
```

云服务器的公网端口和端口转发规则仍需要管理员在云平台操作；本程序不会绕过防火墙。部署前请阅读[完整安装与使用手册](安装与使用手册.md)中的备份、恢复、限制和运维章节。
